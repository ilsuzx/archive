소개

Last.fm 연결

사운드 태그 · 비슷한 곡 · 아티스트 소개 일부는 Last.fm을 써요. 무료 API 키를 한 번 입력하면 이 브라우저에만 저장되고, 파일이나 백업에는 들어가지 않아요. 키는 여기에서 무료로 받을 수 있어요('API key'만 필요해요).

백업과 복원

데이터는 이 브라우저에만 저장돼요. 파일로 내보내 두면 기기를 바꾸거나 캐시를 지워도 복원할 수 있어요.

노래 추가

음악 검색검색 기준을 고르고 입력하세요. 기본은 통합 검색이에요.
곡명·아티스트명으로 검색했는데 원하는 곡이 안 나오면 '통합'으로 바꿔 다시 검색해 보세요. 통합이 가장 넓게 찾아줘요.

앨범 추가

앨범 검색'선택'은 앨범 정보와 커버만 입력하고, '통째로 추가'는 수록곡 전체를 노래로 한 번에 추가해요.
